# Data-quality findings log

Running log of data-quality findings about the sources used by Access Deserts. Each entry states
what was found, the evidence (counts from a specific run or inventory), the impact on the analysis
and how it is handled. Feeds the Reliability page and the Limitations section.

Evidence sources: run.json / quality.json of the named run, and the layer inventory
`pipeline/discovery/inventory-2026-10-05.md` (GeoSampa WFS, 5 Oct 2026). Counts change between
runs; quality.json recomputes the measurable ones on every run.
